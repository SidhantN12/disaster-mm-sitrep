03

Where the modalities meet

Everything before the highlighted block is shared and frozen across all three runs, so the fusion mechanism is the only variable in the comparison.

feature-level

Early fusion

image→ViT→concat + MLP→decoder
reports→text enc.↗

Both vectors are glued together into one code at the input. Nothing downstream can tell the modalities apart, and no mechanism can weigh one report against another.

decision-level

Late fusion

image→own encoder + decoder↘
gate→output
reports→own encoder + decoder↗

Two separate networks that never exchange a single activation. One learned scalar decides how much of each to believe — and in training it never moved off 50/50.

cross-attention

Hybrid fusion

patch tokens↘
co-attention→decoder
report tokens↗

Report words query image regions and image regions query report words, at every layer. Each generated word then picks its own evidence — which is what section 01 is drawing.

04

What the comparison found

Five seeds per configuration, 30 training runs in total. Report relevance — does this tile's bag of reports contain anything about this tile — is the one task that genuinely needs the text, so it is the task that separates the three.

Report relevance after 3 epochs

weighted F1 · vertical rule is the no-learning baseline

Only cross-attention clears the baseline. The other two sit below a constant predictor.

Report relevance after 12 epochs

weighted F1 · same baseline

Given four times the budget, all three learn it. Cross-attention's advantage is getting there first, not getting there alone.

Does it actually read the text?

F1 lost when every report is deleted

At the short budget, deleting the entire text modality changed early and late fusion's answer by exactly nothing. A model whose output is identical with and without an input is not using it.

Late fusion converges on emitting almost one sentence for every tile — the predictable result of averaging two probability distributions. This gap does not close with budget.

The result that holds under every condition we tested: damage classification scores 0.837 weighted F1 under all three mechanisms, at both budgets, on every seed — exactly the score of always guessing “destroyed”. 83% of tiles carry that label, because a tile inherits the worst damage among its ten structures. No fusion mechanism can rescue a target that is nearly constant; the label definition has to change.
